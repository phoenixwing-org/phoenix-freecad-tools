# 版本与发布约定

当前源码候选为 **0.3.2**，统一收纳0.3.1之后的功能改进，尚未正式发布。

## 一个交付批次，一个版本

读取诊断、Desk/聊天接入、当前文档工具、缩略图、外观、模型与字号、界面整理等改进归入同一批0.3.2。界面修正、补测试及隐私清理继续使用该候选号；达到交付边界并开始下一批时再决定升号。旧文档中的0.4.0–0.10.0是未发布内部标识，不作为正式发行版本。Desk应用属于另一产品，独立维护版本。

## 分开记录状态

- 源码候选：版本号只表示源码身份，不证明已安装、已验收或已发布。
- 内存加载版本：以FreeCAD已加载模块实际报告为准；磁盘更新不会自动替换它。
- 本地归档：实际源码/安装包及清单绑定提交和字节摘要，只覆盖其明确列出的内容。
- 正式发布：PR、合入、标签、Release与npm等动作分别执行并记录结果，不从本地归档推断。

## 精简历史与隐私

公开候选仅继承已经审查的最小历史。合并功能提交不能消除父提交中的私有内容；需要时从初始许可与受审源码建立独立候选，并检查bundle的全部可达/物理对象及独立恢复结果。旧分支、标签和包在单独审查前不能随候选分发。

整理前保留仓库外、仅当前用户可访问的恢复副本。不要通过推送全部分支/标签或镜像发布带回旧历史；不自动改写远端或覆盖公开标签。正式发布还须完成[发布计划](RELEASE-PLAN.md)中的原生与平台门槛。外观、设计写入、会话复用和Desk部署等待办不会因压缩提交而视为完成。
