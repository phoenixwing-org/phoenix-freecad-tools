# 工具条、聊天与面板约定

当前统一候选 **0.3.2**；0.3.1为归并基线，旧内部迭代及历史验证按[版本约定](VERSIONING.md)区分。界面继承FreeCAD原生主题，只调整自有控件，不改全局样式。

## 主工具条

前三个MCP控件固定仅图标，其余全部业务入口使用本项目原创SVG，默认图标加文字。在齿轮**设置 → 工具条显示**选择“仅图标”或“图标和文字”，保存后立即应用；tooltip、菜单及可访问名称保留文字。

| 入口 | 行为 |
| --- | --- |
| `PhoenixTools_MCPStatus` | 运行绿点、停止/停止中红点；只查看实际本机桥接详情 |
| `PhoenixTools_ToggleMCP` | 灰色三角启动、方块停止，停止中不可用；手动停止固定确认且默认取消 |
| `PhoenixTools_Settings` | 灰色齿轮，语言、业务图标显示、自启动及只读服务信息 |
| `PhoenixTools_DocumentTools` | 当前文档信息、缓存尺寸、Markdown和缩略图Dock |
| `PhoenixTools_AxonometricFit` | 一次轴测并适合窗口 |
| `PhoenixTools_Appearance` | 非模态小外观窗口，随机色与透明度实时预览，OK一次撤销，Cancel/Esc在归属有效时恢复 |
| 其余业务入口 | 命名修正、链接同步、零件属性、Desk与AI聊天，保留各自原行为 |

状态不只靠颜色表达；动作形状、tooltip、菜单和详情同时说明。桥接绿点不证明Node、聊天或Desk已连接。停止不取消已经开始的原生操作，不引入暂停语义。

工具条显示使用本插件`ToolbarButtonStyle=icon_text|icon`偏好，读取不切语言。配置只影响Phoenix业务按钮；MCP三个控件固定图标。Qt支持按按钮设置`toolButtonStyle`，见[Qt QToolButton](https://doc.qt.io/qt-6/qtoolbutton.html)。图标未借用外部图标集，来源见[品牌资源](BRANDING.md)。

## 原生聊天

首行是当前文档、轴测Fit、外观三个紧凑图标，右侧齿轮折叠配置。它们调用同一工作台命令，不另复制CAD业务。主面板保留状态、聊天记录、输入、发送/停止；断开或报错时显示连接，未登录时显示官方登录。

Codex路径、工具开关及Node/CLI、断开、模型和字号、复制/官方说明/关闭、桥接说明和工具调用诊断全部收进齿轮。工具诊断为空时隐藏。折叠、改字号或打开快捷工具不自动重连或重建现有聊天。

## 窄面板与对象范围

文档和聊天Dock最低宽约300逻辑像素；长文档/模型名不影响最小宽度，说明换行，按钮必要时分行，页签可滚动，整体过高时纵向滚动。缩略图随实际可用宽度缩放冻结预览，不反向撑宽其他页签。

当前文档默认跟随活动目标，也可下拉固定查看；固定后台目标的缩略图页提供明确激活按钮。只读跟随/勾选不改树选择或相机。

三个业务编辑工具使用表内“处理”复选框。完全无树选择时才推荐零件级对象，有选择但全部不适用时留空；内部特征手动勾选。命名/链接实时差异、属性逐项确认，最终只修改明确范围，快照复核、撤销和不自动保存保持。

语言默认中文，设置可选English并立即刷新自有界面；不跟随FreeCAD全局语言。开机自启默认关闭，仅在下次FreeCAD GUI启动做一次有界尝试；手工停止不自动拉起，旧停止确认偏好不能关闭确认。
