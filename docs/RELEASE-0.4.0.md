# Phoenix FreeCAD Tools 0.4.0

**状态：先前候选，未正式发布；当前候选见[0.4.1](RELEASE-0.4.1.md)。最后已发布版本仍为0.3.2。** 本页为0.4.0候选发行说明，尚未完成本版本的最终验证、实际制品审查与正式发布。0.3.2的发行内容、校验值和验收范围保留在原发行记录中。

旧文档中的内部0.4.0–0.10.0标签继续按历史语义保留；它们不表示本次0.4.0已经发行，也不作为本候选的验收证据。

本候选修正内置Codex聊天的连接与会话版本边界，明确支持CLI `0.160.0` 和 `0.167.0-alpha.3.2`。初始化、会话恢复和本地登记须匹配实际运行版本；未知版本明确拒绝，既有会话不跨版本自动迁移。登录、工具权限、实例发现及写入确认的校验保持有效。

通过正式进程适配与控制器，在原生Qt环境中完成了官方浏览器登录、真实文字回复、中断后继续回复，以及重新连接复用该独立登录状态的验证。此项验证没有调用CAD工具，不能代替FreeCAD内的完整界面、图纸或各平台验收。验证凭据、消息与本机回执不随源码或安装包分发。

工作台、Node MCP服务与运行时标识采用0.4.0；桥接协议保持v1。版本变化不自动迁移既有聊天登记，也不扩大实例发现的兼容范围。普通工作台工具仍可独立使用。

发行前须补齐最终交付范围、聊天与MCP验证、原生平台验收、安装及恢复结果，并核对两份实际安装包及其校验值：
