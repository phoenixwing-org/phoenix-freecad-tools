# 验证与验收

源码测试、独立人工示例、原生界面验收和正式发行分别核验。自动化通过不代表任意工程、现有会话或跨平台环境均已验收。私有工程、实际宿主操作过程及其去标识摘要不作为公开验证材料；历史运行回执不随源码分发。

## 可复现的自动化检查

在满足 package.json 的 Node 版本且已准备依赖的开发环境执行：

```sh
npm run typecheck
npm run build
npm test
npm run test:python
```

测试覆盖协议与类型校验、GUI 调度、事务所有权、失败回滚、受管理安装以及聊天与 Desk 的独立注入接口。测试输入应为独立构造的中性数据，不从真实工程或讨论转换。需要原生 FreeCAD 的验收必须另在独立配置和人工文档中进行，不能把纯 Python 或注入 Qt 测试称为原生 CAD 验收。

[分发材料回归](verification-managed-addon.json)仅记录独立临时 package/Mod 的文件验收：安装器 44 项、完整 Node 166 项和 Python 打包 6 项通过。离线构建包在独立临时 Mod 核验 dry-run、法律材料字节与指纹、幂等重装、卸载备份和缺材料拒绝；不安装到用户目录，不连接 FreeCAD 或 Desk。使用说明见[受管理安装](ADDON-MANAGED-INSTALL.md)。这不证明全新依赖安装、原生 GUI 或跨平台发行通过。

## 原生验收要求

- 文档读取：区分活动文档、固定文档、未保存状态、缓存值与不可读值；读取不得触发保存或改变选择。
- 改名和属性：完整预览后明确确认；检查过期状态、同名冲突、事务所有权、失败恢复、撤销和重做。
- 有限Pad Length：独立人工未附着草图/首个Pad，核对typed快照、完整预览、真实人工确认、一次局部重算、参数/Shape/体积/包围盒反验、拒绝范围、失败恢复及undo/redo；源码与fake测试不代替原生验收。
- 外观与缩略图：独立人工几何检查实时预览、OK、取消、Esc、关闭、透明材质和相机恢复；生成的图片需目视核对。
- 聊天与 MCP：独立会话核对连接、发送、停止、失败清理、工具清单与审批边界；不读取其它会话的凭据或历史。
- Desk：使用独立受控服务核对 absent/ready/unavailable/incompatible，确认未知实例不会被接管，浏览器请求不冒充页面目视验收。
- 分发：从实际源码 ZIP、Addon ZIP、Node tgz 和候选 Git bundle 检查内容、许可、元数据、摘要和恢复结果；不把工作区扫描代替实际包检查。
