# 当前文档工具

正式版本为 **0.3.2**；本轮显示单位属于尚未发布的后续修正，源码版本号沿用不代表已包含在发行包中。最终原生与安装验收见[验证记录](VERIFICATION.md)。旧0.4.0–0.10.0仅为[未发布内部迭代标签](VERSIONING.md)，历史事实保留，当前操作以下文为准。

通过 Phoenix Tools → **当前文档工具** 或聊天顶部文档图标打开非模态Dock，可停靠或浮出。面板最低宽约300逻辑像素，长名称、信息行与缩略图不撑大整个侧栏；说明可换行，页签可滚动，内容过高时纵向滚动。

## 跟随或固定查看

默认首项“跟随活动文档”随FreeCAD左侧切换的活动文档更新。下拉明确选择某个打开文档可固定查看；再选首项恢复跟随。轮询只比较活动文档Name和打开文档集合，变化后才更新范围，平时不扫描几何。

只读跟随、下拉切换和勾选不激活文档、不改树选择或相机。固定文档在后台时，“缩略图”页显示**激活此文档**；只有点击该按钮才显式切换活动目标。固定目标关闭后回退跟随；全部关闭后显示空状态。对象范围可折叠，固定查看期间活动文档变化保留勾选和编辑器滚动位置。

面板读取当前打开的FreeCAD内存数据，包括未保存修改。完全没有原始树选择时推荐合适顶层对象；已有选择但不适用时不扩大为整文档。Body内部特征不默认全选，避免重复测量。模型内容修改后用**刷新当前内存**取得新快照。

## 信息、属性与缓存尺寸

信息包括内部Name、显示Label、对象数量、修改/待重算标记、编辑状态和Body/Tip。不可取得的状态保留未知，不用零或否代替。

属性汇总默认只读勾选对象的五个正式字符串字段：`PartNumber`、`PartVersion`、`TypeCode`、`ModelSeries`、`PartName`。顶部小工具条右侧的齿轮打开**读取属性设置**：每行一个内部字段名，也可用逗号分隔；最多20项，重复或非法名称明确拒绝。留空停止属性读取，**恢复常用字段**恢复默认五项。设置仅在当前面板生效，关闭重开恢复默认；不创建、推荐、修改属性或保存偏好。

显式字段支持`App::PropertyString/Integer/Float/Bool/Enumeration`。枚举仅读当前选中字符串，不读取选项列表，不把索引或布尔值猜成名称。显式字段另支持`IntegerConstraint/Percent`当前整数及`FloatConstraint/Precision`当前有限浮点值；不读取约束范围或setter四元tuple，也不把Precision推断为mm。

另支持明确选择的`App::PropertyStringList/IntegerList/FloatList/BoolList`，保留次序、重复项、0、false和空字符串；原生BoolList返回的tuple也按布尔列表读取，空列表与未知/缺失分别报告。每字段最多100项，清洗后的紧凑JSON列表最多2 KiB UTF-8；超限整字段不发布值，标记未知及已截断，并保留`item_count`和固定`limit_reason`，不把部分列表当作完整结果。列表项严格匹配原生类型，不把整数和布尔互换；数值须有限且整数在有符号64位内。文本控制字符处理有标记，信息和Markdown共用冻结列表；不展开任意嵌套对象或读取LinkList；VectorList和PlacementList遵循下面的独立合同。这仍是属性读取，不进行数量聚合。

显式字段另支持`Vector/VectorDistance/Position/VectorList`：仅复制原生有限浮点xyz。偏移和位置按属性类型标内部mm；普通向量及列表保持单位、坐标系未声明，不应用Placement或解析Link来源。零向量、空列表保留，列表超过100项或完整值2 KiB时整项未知、不发布部分结果；限制是getter之后的处理/输出边界。信息及Markdown显示同一冻结值和来源，完整DTO见[属性读取合同](PROPERTY-READING.md)。

显式字段另支持`Rotation/Placement`：旋转只复制原生xyzw四元数，Placement分开复制Base xyz和旋转；平移内部mm、旋转无量纲。不相乘、不转换坐标系、不归一化或解析Link；零平移／单位旋转保留，坏值或嵌套异常整项未知或读取失败，信息和Markdown使用同一冻结DTO。完整字段与原生验证边界见[属性读取合同](PROPERTY-READING.md#旋转与-placement)。

后续未发布修正增加显式`PlacementList`：按原顺序读取位姿副本，保留重复和空列表，逐项使用相同的混合单位说明；不推导对象数量或装配世界坐标。100项／完整值2KiB上限先到即整字段未知，任何坏成员也不发布前缀；复制和Markdown使用冻结列表。它不扩大默认五字段，原生验收状态见[位姿列表合同](PROPERTY-READING.md#位姿列表后续修正尚未发布)。

量值支持`Quantity/QuantityConstraint/Length/Distance/Angle/Area/Volume/Mass/Density/Speed/Acceleration/Force/Pressure/Frequency/Power/Temperature`；固定类型的原生维度须与其物理预期一致，矛盾时不发布数值。

Quantity从原生`Value`和八维`Signature`生成内部基底表达式（`mm,kg,s,A,K,mol,cd,deg`），不读取显示字符串或猜换算。组合维度也可报告，例如力为`mm*kg*s^-2`，不能把未换算数值标成N。非法/缺失维度为未知；Value、Unit或Signature的非AttributeError读取异常保留为读取失败；AttributeError观测为不可读取，保持未知。0、false、空值、缺失、未知和读取失败分别显示；这仍是一般对象属性读取，不是BOM数量聚合。完整类型、单位和失败边界见[属性读取合同](PROPERTY-READING.md)。

单文本值最多2 KiB UTF-8，截断/控制字符处理有标记；整笔最多128 KiB，超限拒绝并提示减少目标。Link使用实例原生报告，不显式解析或代写来源，本地/继承来源仍未验证。自由文本和自选字段可能含敏感内容，省略FileName不代表所有内容匿名。

读取设置另有**使用 FreeCAD 显示单位**，默认关闭。开启后，尺寸与显式量值显示本次原生单位系统生成的文字；内部mm及Value/Signature保留，复制与Markdown使用同一份冻结结果。取消保留原选项，关闭重开恢复默认；不修改全局单位方案，缺失或异常时明确提示。见[显示单位合同](PROPERTY-READING.md#跟随-freecad-显示单位后续修正尚未发布)。独立未保存样件已通过实际Qt设置、Imperial长度显示、刷新、内存复制接收和完整Markdown导出确认验收；文件选择为QA注入，不代表系统文件框或任意单位方案全部通过。

尺寸来自目标当前报告的`Shape.BoundBox` X/Y/Z，单位mm。不重算、求解、验证几何或额外应用Placement，不展开装配世界变换；Link仅读实例缓存Shape。空Shape、异常和不可读值分别报告。这些包络不等于制造尺寸、公差或净间隙。

候选/目标上限200，元数据扫描上限2000对象；超限明确提示。首版支持已识别的Part、Body、Sketch和Link类对象，不宣称通用第三方对象或完整装配查询。

## 复制与 Markdown

复制只在点击时写剪贴板。Markdown默认省略文档FileName，但模型名和属性仍可能含用户内容，分享前请检查。

**导出 Markdown**先打开保存框：已保存CAD默认同目录、同stem的`.md`；未保存文档只建议安全文件名，由用户选择目录。之后展示内容与目标确认，覆盖已有文件单独确认，目标或目录身份变化时拒绝覆盖。只写明确选定的Markdown，不保存CAD。目录与祖先的身份在内容确认时冻结。macOS等支持目录句柄的平台把暂存、发布和清理锚定原目录，避免写入被替换的同名目录；不支持的平台保留路径前后校验，尚无等同的原生保证。发布前反验暂存文件身份及完整字节，发布后核对目标身份与摘要。错误分别保留文件发布与暂存清理的结果：可能已写出，或已发布但清理未确认时，界面明确提示检查目标、不要重复导出；不会自动删除最终文件或重试。覆盖仍是指纹检查后替换，不是跨进程比较交换，也不承诺掉电持久性。已有目标超过1 MiB时拒绝读取及覆盖。

macOS独立人工样件的真实原生对话框自动化已验证保存框取消、新建导出、覆盖取消与确认覆盖；确认前不改写目标，确认后输出与完整预览的UTF-8字节一致。未保存样件的默认文件名已实测；已保存CAD的同目录、同stem建议已通过真实Qt模式文件框、活动文档切换及工具确认按钮验证；macOS原生NSSavePanel的路径建议仍待验。上述导出验收未读写剪贴板，自动化按钮操作不构成用户人工验收或批准，也不证明跨平台通过。另在独立未保存文档以真实原生预览/确认按钮验证新目标目录被换、已有覆盖目标目录被换、取消、普通新建及普通覆盖导出五项；该轮文件选择为QA注入路径，不能替代系统文件框验收。

新发布核心另在独立FreeCAD1.1.4/Qt6.8.3验证取消、新建、覆盖、已写出后异常与清理失败六项；文件选择和消息接收为QA注入，完整预览与确认按钮使用真实Qt控件，源模型和选择保持，不保存CAD。此检查不替代系统文件框及跨平台验收。

macOS覆盖时先显示系统“Replace/替换”确认，随后仍需完成工具自己的完整内容预览（Markdown）或目标确认（PNG）；工具确认中的Cancel仍阻止写入。[Qt的QFileDialog说明](https://doc.qt.io/qt-6.8/qfiledialog.html#Option-enum)明确，`DontConfirmOverwrite`不用于macOS原生文件对话框。

## 工具条的视图和外观

当前文档面板使用顶部紧凑图标栏，与聊天面板共用文档工具、轴测Fit和对象外观三个入口，读取属性设置的齿轮位于右侧；悬停可查看名称。文档图标只显示已有面板，不额外刷新或切换文档。轴测Fit图标组合执行原生轴测视图和Fit，外观图标复用同一原生预览窗口。主工具条保留这些入口，文档面板不再放重复的大型快捷区。

外观图标打开小型非模态窗口，范围锁定为打开时明确选定的活动文档对象。随机色按钮实时预览；透明度常用档位为不透明（0%）、微透（25%）、半透（50%）、高透明（75%），保留0–100%滑条/数值框微调。当前值匹配时高亮对应档位，混合值或其他数值不高亮；点击档位直接预览，不会另开事务。OK将整次预览提交为一笔可撤销事务，Cancel、Esc或关闭在仍拥有该事务且没有外部修改时恢复初始外观。窗口不自动改跟随目标，不重算、不保存，不修改Link来源。若目标、事务身份或外部操作使归属失效，停止处理并报告，不接管、提交或取消其他修改。

非模态预览绑定`App.setActiveTransaction`本次返回的数字ID，关闭只调用带该ID的原生接口。分配、材质构造、提交或回滚的同步回调期间，重复确定、取消或关闭不会终结面板，也不排队重放；正常空闲时的Cancel、Esc和关闭保持恢复语义。最终材质读取后再次核对事务及外部修改；关闭结果未知时停止，不再次提交或回滚。它与下文直接MCP路径分别验收，不声明任意同步回调的完整隔离。

外观采用完整材质快照和写后核对，保留未修改字段。普通同文档单实例Link通过实例材质覆盖实现；多层、数组、子元素、跨文档来源以及同时选择来源与其Link仍拒绝整笔操作；尚未启用实例覆盖且来源含不同逐面材质时也拒绝，已有独立实例覆盖使用本地单材质。最多100对象、每对象256材质、完整计划128 KiB。属性数值不证明最终屏幕像素透明度。

同文档单实例Link指向独立Body（Sketch→Pad→Pocket）已用真实Qt控件验证透明度／随机色、Cancel/Esc/关闭、OK及Undo/Redo，核对来源Body与Pad/Pocket、另一同源Link的完整材质及几何保持；原生数组、多层和来源＋Link混合范围已验证修改前拒绝。跨文档原生样件要求保存来源文件，本轮没有为此保存CAD，因此该原生拒绝链仍待验；历史特征、多层／数组支持和更广显示上下文也不据此宣称完成。

MCP的`set_appearance`走直接prepare/apply，与可取消的非模态预览窗口分开验收。直接应用在任何原生预检前将计划标为applying，阻止同token同步重入；使用`App.setActiveTransaction`返回的数值ID绑定归属，不把打开回调后碰巧存在的事务认作本次事务。每次材质setter前后、提交／回滚前复核ID和目标，使用`App.closeActiveTransaction(abort,id)`关闭，随后检查全局已空闲和完整材质。提交一旦调用，后续异常不再次提交或取消；结果不明确时报未确认，不宣称已恢复。缺少相应原生API即拒绝，不回退到只有布尔opened标记的路径。[分配ID的Python API](https://github.com/FreeCAD/FreeCAD/blob/1.1.0/src/App/ApplicationPy.cpp#L1110-L1157)

同token成功重放只返回已完成摘要，不重新写入；失败计划不可重用，MCP仍须按原requestId查询原任务。这是事务身份和重入保护，不是任意原生回调、跨文档副作用或同ID外部修改的完整隔离；非模态窗口另有自己的observer污染检测，不能把它的证据外推给直接MCP路径。

历史内部0.6–0.8曾提供三个文档面板快捷按钮和完整材质JSON预览/应用界面，其37%逐材质修正、撤销重做及来源保护证据继续保留；这些旧布局不再是当前使用步骤。命名与属性写入仍保留完整差异预览和确认。

## 缩略图与 PNG

在“缩略图”页点击**生成预览**：尺寸256/512/1024，背景白色/当前/透明，默认临时轴测Fit。捕获后恢复完整原相机，不留临时视角，不改材质、显隐、树选择或CAD文件。

透视构图根据同坐标场景的包围盒、包围球和较窄半视角计算留白及裁剪面，并以Coin实际保存的binary32相机值复核视锥包含关系；无法安全表示时拒绝，不接受溢出或裁切的计划。正交构图仍沿用原生Fit。自定义相机祖先变换及视图额外的viewport变换尚未据此宣称支持；这不指已验收的原生CROP mapping。

每次捕获先读取FreeCAD的`SavePicture`图像后端。macOS显式选择`CoinOffscreenRenderer`时，在临时改相机及原生捕获前拒绝，包括关闭轴测Fit的情况；独立FreeCAD1.1.4检查中该后端触发CGL错误并使进程退出，不能依赖Python异常处理恢复。此门禁不表示所有macOS或FreeCAD版本均已测得崩溃。

图像后端若为`GrabFramebuffer`，轴测Fit会在临时改相机之前明确拒绝；该后端可能读取旧帧缓冲，也不遵守全部画布和背景参数。工具不修改图像后端、不自动换后端重试或缩放补边；可由用户另行选择默认或`FramebufferObject`后端。关闭轴测Fit时仍校验返回PNG的请求尺寸，不能据此保证Grab后端已刷新视图或应用所选背景。配置读取失败时明确停止。

相机字段恢复也可能同步触发[Coin即时传感器](https://www.coin3d.org/coin/classSoDelayQueueSensor.html)。捕获在完整恢复和反验之后再次核对原文档、GUI文档、三维视图及事务/编辑状态；此时目标变化或进入忙碌状态就拒绝返回图像，不把相机已恢复当作整次捕获成功，也不切回文档或关闭其他操作开启的事务。原捕获错误保持，无法确认相机恢复时优先报告恢复失败。

图像包括活动文档整个可见三维视图，**不按对象勾选过滤**，也不是桌面截图或TechDraw导出。后台目标需先明确激活；编辑或事务中拒绝捕获。切换目标或活动状态使旧预览失效，返回该活动文档后恢复生成按钮，需要重新生成。面板缩窄仅缩放冻结图像，不重新读取或捕获CAD。

缩略图下方使用有界的只读纯文本区，长连续名称也可换行，说明过多时纵向滚动查看；文本不解析HTML。预览可随窄窗口缩小，状态区限制高度，为生成和导出按钮保留空间。滚动、调整窗口或字体只改变已有预览的显示，不再次捕获或导出。

**导出 PNG…**写当前冻结预览的原始字节，不再次捕获。已保存CAD默认同目录/同stem的`.png`，未保存文档由用户选择目录；保存框之后仍有默认取消的确认，覆盖单独确认，并核对文件/目录身份。目录须已存在且无符号链接。支持目录句柄的平台把暂存、发布与清理锚定原目录，反验暂存身份、冻结字节及最终PNG散列；不删除被替换的同名外来暂存。非dirfd平台仍只有路径前后检查，须另行原生验收。发布瞬间目录才变化时，原目录可能已有PNG；先检查结果，不直接重导。PNG不写FCStd，也不更新工程内嵌缩略图。

macOS独立人工样件的真实原生对话框自动化已验证保存框取消、新建导出、覆盖取消及确认覆盖。覆盖取消保留原文件的字节、文件身份与修改时间；确认导出与冻结512×512预览逐字节一致，改变捕获选项后仍只捕获一次。未保存样件的默认文件名已实测；已保存CAD的目录建议仅经纯逻辑验证。该结果不等于用户人工验收或跨平台通过。

仅支持8位非交错RGB/RGBA PNG，最多4 MiB及1024×1024像素；去除作者、文本、EXIF、时间等附带元数据，保留像素和必要色彩/透明信息，ICC暂不支持。图像仍可能含用户模型内容；当前颜色沿用三维视图；专用浅灰风格、工程内嵌缩略图、引用及量值列表等更广属性类型与BOM聚合仍在后续计划。


专用浅灰风格还需要独立渲染适配：目标FreeCAD 1.1.0的[面集渲染分支](https://github.com/FreeCAD/FreeCAD/blob/1.1.0/src/Mod/Part/Gui/SoBrepFaceSet.cpp#L762-L958)会自行设置材质，不能把上层Coin覆盖当作所有实体都有效；独立提取几何还必须保留隐藏子面与显示上下文。当前没有加入未经验证的样式入口，也不临时改写零件材质。
