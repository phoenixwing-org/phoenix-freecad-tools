# 当前文档工具

适用统一候选 **0.3.2**；最终原生与安装验收见[验证记录](VERIFICATION.md)。旧0.4.0–0.10.0仅为[未发布内部迭代标签](VERSIONING.md)，历史事实保留，当前操作以下文为准。

通过 Phoenix Tools → **当前文档工具** 或聊天顶部文档图标打开非模态Dock，可停靠或浮出。面板最低宽约300逻辑像素，长名称、信息行与缩略图不撑大整个侧栏；说明可换行，页签可滚动，内容过高时纵向滚动。

## 跟随或固定查看

默认首项“跟随活动文档”随FreeCAD左侧切换的活动文档更新。下拉明确选择某个打开文档可固定查看；再选首项恢复跟随。轮询只比较活动文档Name和打开文档集合，变化后才更新范围，平时不扫描几何。

只读跟随、下拉切换和勾选不激活文档、不改树选择或相机。固定文档在后台时，“缩略图”页显示**激活此文档**；只有点击该按钮才显式切换活动目标。固定目标关闭后回退跟随；全部关闭后显示空状态。对象范围可折叠，固定查看期间活动文档变化保留勾选和编辑器滚动位置。

面板读取当前打开的FreeCAD内存数据，包括未保存修改。完全没有原始树选择时推荐合适顶层对象；已有选择但不适用时不扩大为整文档。Body内部特征不默认全选，避免重复测量。模型内容修改后用**刷新当前内存**取得新快照。

## 信息、属性与缓存尺寸

信息包括内部Name、显示Label、对象数量、修改/待重算标记、编辑状态和Body/Tip。不可取得的状态保留未知，不用零或否代替。

属性汇总默认只读勾选对象的五个正式字符串字段：`PartNumber`、`PartVersion`、`TypeCode`、`ModelSeries`、`PartName`。文档下拉旁的齿轮打开**读取属性设置**：每行一个内部字段名，也可用逗号分隔；最多20项，重复或非法名称明确拒绝。留空停止属性读取，**恢复常用字段**恢复默认五项。设置仅在当前面板生效，关闭重开恢复默认；不创建、推荐、修改属性或保存偏好。

显式字段支持`App::PropertyString/Integer/Float/Bool/Enumeration`。枚举仅读当前选中字符串，不读取选项列表，不把索引或布尔值猜成名称。量值支持`Quantity/Length/Distance/Angle/Area/Volume/Mass/Density/Speed/Acceleration/Force/Pressure/Frequency/Power/Temperature`；固定类型的原生维度须与其物理预期一致，矛盾时不发布数值。

Quantity从原生`Value`和八维`Signature`生成内部基底表达式（`mm,kg,s,A,K,mol,cd,deg`），不读取显示字符串或猜换算。组合维度也可报告，例如力为`mm*kg*s^-2`，不能把未换算数值标成N。非法/缺失维度为未知；Value、Unit或Signature的非AttributeError读取异常保留为读取失败；AttributeError观测为不可读取，保持未知。0、false、空值、缺失、未知和读取失败分别显示；这仍是一般对象属性读取，不是BOM数量聚合。完整类型、单位和失败边界见[属性读取合同](PROPERTY-READING.md)。

单文本值最多2 KiB UTF-8，截断/控制字符处理有标记；整笔最多128 KiB，超限拒绝并提示减少目标。Link使用实例原生报告，不显式解析或代写来源，本地/继承来源仍未验证。自由文本和自选字段可能含敏感内容，省略FileName不代表所有内容匿名。

尺寸来自目标当前报告的`Shape.BoundBox` X/Y/Z，单位mm。不重算、求解、验证几何或额外应用Placement，不展开装配世界变换；Link仅读实例缓存Shape。空Shape、异常和不可读值分别报告。这些包络不等于制造尺寸、公差或净间隙。

候选/目标上限200，元数据扫描上限2000对象；超限明确提示。首版支持已识别的Part、Body、Sketch和Link类对象，不宣称通用第三方对象或完整装配查询。

## 复制与 Markdown

复制只在点击时写剪贴板。Markdown默认省略文档FileName，但模型名和属性仍可能含用户内容，分享前请检查。

**导出 Markdown**先打开保存框：已保存CAD默认同目录、同stem的`.md`；未保存文档只建议安全文件名，由用户选择目录。之后展示内容与目标确认，覆盖已有文件单独确认，目标或目录身份变化时拒绝覆盖。只写明确选定的Markdown，不保存CAD。

## 工具条的视图和外观

当前文档面板已移除重复的大型快捷区，视图与外观统一放在主工具条及聊天顶部小工具条。轴测Fit图标组合执行原生轴测视图和Fit。

外观图标打开小型非模态窗口，范围锁定为打开时明确选定的活动文档对象。随机色按钮及0–100%滑条/数值框实时预览；OK将整次预览提交为一笔可撤销事务，Cancel、Esc或关闭在仍拥有该事务且没有外部修改时恢复初始外观。窗口不自动改跟随目标，不重算、不保存，不修改Link来源。若目标、事务身份或外部操作使归属失效，停止处理并报告，不接管、提交或取消其他修改。

外观采用完整材质快照和写后核对，保留未修改字段。普通同文档单实例Link通过实例材质覆盖实现；多层、数组、子元素、跨文档来源、不同逐面来源材质以及同时选择来源与其Link仍拒绝整笔操作。最多100对象、每对象256材质、完整计划128 KiB。属性数值不证明最终屏幕像素透明度。

历史内部0.6–0.8曾提供三个文档面板快捷按钮和完整材质JSON预览/应用界面，其37%逐材质修正、撤销重做及来源保护证据继续保留；这些旧布局不再是当前使用步骤。命名与属性写入仍保留完整差异预览和确认。

## 缩略图与 PNG

在“缩略图”页点击**生成预览**：尺寸256/512/1024，背景白色/当前/透明，默认临时轴测Fit。捕获后恢复完整原相机，不留临时视角，不改材质、显隐、树选择或CAD文件。

图像包括活动文档整个可见三维视图，**不按对象勾选过滤**，也不是桌面截图或TechDraw导出。后台目标需先明确激活；编辑或事务中拒绝捕获。切换目标或活动状态使旧预览失效，返回该活动文档后恢复生成按钮，需要重新生成。面板缩窄仅缩放冻结图像，不重新读取或捕获CAD。

**导出 PNG…**写当前冻结预览的原始字节，不再次捕获。已保存CAD默认同目录/同stem的`.png`，未保存文档由用户选择目录；保存框之后仍有默认取消的确认，覆盖单独确认，并核对文件/目录身份。目录须已存在且无符号链接。PNG不写FCStd，也不更新工程内嵌缩略图。

仅支持8位非交错RGB/RGBA PNG，最多4 MiB及1024×1024像素；去除作者、文本、EXIF、时间等附带元数据，保留像素和必要色彩/透明信息，ICC暂不支持。图像仍可能含用户模型内容；当前颜色沿用三维视图；专用浅灰风格、工程内嵌缩略图、列表/引用等更广属性类型与BOM聚合仍在后续计划。


专用浅灰风格还需要独立渲染适配：目标FreeCAD 1.1.0的[面集渲染分支](https://github.com/FreeCAD/FreeCAD/blob/1.1.0/src/Mod/Part/Gui/SoBrepFaceSet.cpp#L762-L958)会自行设置材质，不能把上层Coin覆盖当作所有实体都有效；独立提取几何还必须保留隐藏子面与显示上下文。当前没有加入未经验证的样式入口，也不临时改写零件材质。
