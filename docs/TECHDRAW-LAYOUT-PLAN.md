# TechDraw 关联尺寸位置建议方案

状态：**开发候选的有限MCP原生闭环及默认新草稿闭环已通过，更多场景继续验收**。开发候选的[关联尺寸](TECHDRAW-DIMENSIONS.md)接受每项显式`xMm/yMm`或明确`placement:"auto"`，允许混合。自动模式独立协商`drawing_dimension_layout`能力，保留工具数量和原手动能力合同。正式发布的0.3.2尚无此布局能力，旧插件在派发自动请求前拒绝；独立Part及Body的正式SDK到原生确认、五类auto/混合写入和Undo/Redo已有有限验收；默认新草稿另经有限Part/Body专项验收；任意页面、制造完整性和官方模型聊天调用仍待验。

## 当前组件与集成边界

| 组件 | 当前候选 | 尚待完成 |

| 冻结计划 | 意图、输入、建议、完整解及原生context绑定现有token；原生回调前后核对，末次读取后纯反验，不重新排布 | 有限样件的原生批准、取消、失效及Undo/Redo已验；未知回滚仍明确失败 |

| 原生适配 | 冻结来源、完整缓存、GUI障碍、图框、单位字体样式及颜色；写入期另核新尺寸实际字体、字号、线宽、箭头和格式 | 实际新样式读取及故意变化拒绝已验；不修偏好来迎合计划 |

纯算法最多64个候选/项、8192次候选搜索和131072次几何比较；兼容性缓存最多8192项。输入/结果分别限64/32KiB。预算耗尽返回完整阻断结果及空坐标列表，不扩大搜索、接受最后冲突位置或部分创建。普通尺寸采用动态最少剩余候选及前向过滤，避免重复探索已知死支；这些是计算预算，不是原生渲染时限承诺。

与同一确切投影端点关联的线性尺寸，允许见证线在该端点对另一尺寸线的正交投影处作必要阶梯连接；交点须位于两条有限线段，不能以共享端点为由放行斜交、平行重叠、邻近而未相交或其它位置的交叉。同圆Radius/Diameter的必要中心接触独立限定，圆外重叠仍拒绝。线条仍是明确标示的估算路径。

原生候选限定已识别A4横向资源的实际字节与纸幅，不用模板图形组的包围盒代替纸面。下部80mm是该有限profile的保守保留区。已有线条使用实际GUI范围的保守矩形障碍，可能多拒位置；不声称精确还原所有原生引线。新的可旋转文字使用保守包围框，仍须对照原生标签。未知字体资源、单位、样式、场景或超限障碍明确阻断，不自动打开图页、建临时节点或重算。

独立Part三视图和Body单视图的Scale0.5正例，已将五类建议交给既有原生写器，并逐坐标核对十个实际标签的完整纸面矩形均包含在原冻结估算框内。原生矩形中心与请求X/Y换算出的中心有小幅偏移，不能把尺寸相等或中心近似当成完整范围相等；此证据仅支持这两个有限正例。图形控件另以实际输入重放多个比例，修复了按框高选字体导致的文字裁切；字号拟合不改估算框、坐标或CAD。极小框内无法完整绘字时保留框与完整提示，放大后显示，不画误导性的截断前缀。

早期默认草稿的几何槽位与标注可用区不协调，投影和必需延伸线会占用保留区。当前[新草稿留白计划](TECHDRAW-DRAFT.md)在完整预览中冻结三视图及标注带；算法另保留原60个线性候选并追加四个纸带边界候选，补足固定外侧lane漏掉的窄带。碰撞、保留区、字体与预算未放宽。默认Part/Body从新建五节点到第二次五类auto确认合计147项检查通过，未手动挪位或改比例；早期失败保留。这只证明有限默认链，不证明任意图纸或制造完整性。

## 尺寸接线阶段的原生验证范围（预先安排视图）

macOS FreeCAD1.1.4/Qt6.8.3中，独立Part与Sketch→Pad→Pocket Body的两组完整五类auto，以及Body的一项显式＋四项auto，经实际分发CLI、正式SDK、桥接及原生确认按钮完成112项检查。确认创建的量值、冻结坐标、实际样式及完整原生文字框均与计划核对；每批只有一个自有事务，单次Undo/Redo分别移除/恢复整批尺寸，来源、Body Tip、选择、相机及未保存状态保持。外部direct apply拒绝后，原token仍prepared，随后仅原生确认可应用。实际确认处理约3.7–4.3秒，不作为任意图纸的性能承诺。

取消、Esc、混合预览、整批无解和偏好变化拒绝另有实际原生观察。故意改新尺寸字号后发生abort并移除新对象，但原生GUI恢复不能完全证明，终态保守返回`PART_ROLLBACK_UNVERIFIED`；不能把对象消失当成完整恢复成功。一次早期驱动序列化Quantity失败及一次负例后profile拒绝均保留，不计为正例通过。

上述112项正例的视图位置由独立fixture在基线前明确安排，**不是默认新草稿布局**；后续147项默认链独立计数。估算标签完整包含这十五个实际标签，不证明任意线条或任意图纸零碰撞。官方模型聊天调用、用户手工验收及其它平台未由这些测试覆盖；实际包的独立临时安装与默认Body验收另见[验证记录](VERIFICATION.md)。

## 需求与首版范围

让调用方明确选择投影边和尺寸类型，由程序建议位置，展示完整布局计划，再由用户在原生面板确认。保留原有显式坐标；不移动已有用户标注，不选择替代边，不推断标注完整性，不添加公差或制造批准。

首版沿用受支持的同文档原生Part::Feature或Body及有界App::Part父链，面向同源1–3个独立DrawViewPart组成的有限页面；新尺寸仍为1–8项，包含`Distance/DistanceX/DistanceY/Diameter/Radius`五类。直线、闭圆、引用和状态限制沿用现有合同，不将样条、圆弧、化妆边、中心线、剖面、投影组、Link或跨文档来源纳入本轮。

优先支持已识别的A4横向图框和可明确声明的可用区域，已有标注作为固定障碍。字体、单位、旧标注或图框区域无法可靠取得时，自动模式明确阻断，显式坐标能力保持原样。不能通过只支持一种尺寸、忽略已有标注或假定整个纸面为空来完成首版。

这里的“完整预览”是完整展示本次请求、建议坐标、已知障碍和限制的**布局计划图**。标签框和线条路径是有界估算，不冒充尚未创建的原生尺寸渲染；确认前的计划图不能证明提交后的实际标签完全相同，也不承诺任意情况零碰撞。

## 接口合同（开发候选）

保留`add_drawing_dimensions`操作及现有预览、原生批准、状态查询链，不增加直接写入或外部确认入口。先用连接状态核对实际插件的独立布局能力；不能只凭Node注册清单推定已加载支持。

外部尺寸行采用严格互斥形式，允许一批内混合：

```json
[
  {"edge":"Edge0","kind":"DistanceX","placement":"auto"},
  {"edge":"Edge2","kind":"Radius","xMm":25,"yMm":18}
]
```

- 显式行保留现有`edge/kind/xMm/yMm`语义；自动行只接受`edge/kind/placement:"auto"`。不把省略坐标当成自动，不接受自动与坐标混写。
- 页、视图、规范Edge0–Edge2047、类型、数量及重复`(edge,kind)`约束保持。显式位置不因本批自动排布而改变。
- 独立`drawing_dimension_layout`版本化能力声明列算法`paper_lanes_v1`、有限profile`freecad_1_1_4_a4_mm_v1`和计算/字节预算。保留现有尺寸能力声明；旧插件缺布局能力时在派发前拒绝自动请求，不降级为猜坐标或脚本。
- prepare先验证自动请求，再将成功建议归一为现有内部显式坐标合同；每项都有确定的`x_mm/y_mm`，后端仍按原有引用、量值和坐标反验规则写入。
- 预览需绑定原始显式/自动意图、算法版本、解出的全部坐标和布局快照。客户端逐项核对边、类型、顺序及显式坐标保持，不能仅凭返回坐标落在数值范围内就接受。
- 计划另给每项位置来源、估算标签框、候选选择原因及冲突诊断。纸面坐标和内部几何不携带文件路径或Qt对象；详细预览保持有界，不通过扩大状态结果预算塞入整页几何。
- 任何一项无解或输入不完整，整批`can_apply=false`并列出固定原因；不以部分成功创建节点。已有显式模式不因增加自动模式而偷偷增加新的布局成功承诺。

自动预览增加严格`layout`对象：`version:1`、`layout_verification:"suggested_only"`、原始内部`intent`、有界`graphics`与固定`reason_code`。成功时顶层`design_request`是完整显式解；无解时为`null`，不生成占位坐标。算法阻断仍保留完整图形输入及冲突；原生输入无法取得时`graphics:null`并给固定原因。手动预览不附加这个对象。原生Qt确认面板使用同一脱离对象，原确认按钮仍是唯一授权入口。

清理未知不会降为普通冲突或成功：固定`DIMENSION_LAYOUT_CLEANUP_UNVERIFIED`提示检查原生状态，不创建可继续的token或重试已有写入。其它布局固定失败码包括`DIMENSION_LAYOUT_UNAVAILABLE`、`DIMENSION_LAYOUT_STALE`和`DIMENSION_LAYOUT_STYLE_UNVERIFIED`，不返回原生诊断。历史状态仍为有界内存摘要，不读取CAD或重启算法。

建议使用`layout_verification:"suggested_only"`等独立语义表达布局结果。现有`measurement_verification`仍只说明关联引用和量值，`projection_verification:"not_checked"`及`manual_review_required:true`继续保留，不能被布局字段替代。

## 纯算法输入与坐标

算法只接收已验证、冻结的普通数据，不调用FreeCAD、Qt场景、文件或服务。原生适配层负责以下读取、上限、身份核对和再次验证：

| 输入 | 要求与边界 |
| --- | --- |
| 请求引用 | 明确Edge和类型；直线端点/长度或闭圆中心/半径来自当前原生缓存，不靠三维Shape边号猜对应关系 |
| 视图 | 身份、来源、有效比例、纸面位置、方向及旋转；其它同页视图和显示内容也进入障碍范围 |
| 来源 | 完整几何、Body/Tip、原生父链身份、局部/全局Placement；沿用现有来源保护，不仅冻结包围盒 |
| 纸面与图框 | 原生宽高、方向、模板身份/资源/文本及已识别保留区；不把未知SVG路径或文件名当作标题栏语义证明 |
| 已有标注 | 身份、引用、位置、实际格式、字体、单位/容差及可取得的完整标签与线条范围；不可读取的内容不能当空障碍 |
| 新标注样式 | 实际将使用的字号、字体资源、格式、单位方案、舍入、线宽、箭头和间距设置；不能默认raw毫米值就是屏幕字符串 |
| 布局约束 | 纸边安全距离、图框/标题栏/其它视图禁入区、固定显式坐标、估算框余量、候选数及计算预算 |

所有布局计算统一为**纸面毫米**。现有引用读取给出未缩放、Qt Y向下的视图局部坐标`(u,v)`；普通独立视图的纸面转换为：

```text
paper_x = view.X + effective_scale * u
paper_y = view.Y - effective_scale * v
```

解出的尺寸X/Y则是相对视图的纸面毫米，不再乘比例。顶部原点的预览图另用`preview_y = paper_height - paper_y`。不能二次施加source或父容器Placement，也不能把过滤后的可见边列表序号当Edge编号。单位为毫米的测量值仍保持物理量，不随纸面比例缩放。

这里的`(u,v)`是读取适配已经统一翻Y的公开DTO。原生Selection/Index getter本身返回未缩放Y向上坐标`(x,y)`，故原始indexed-cache bounds的转换应是`(view.X + scale*x, view.Y + scale*y)`。`getVisibleEdges(False)`则直接返回已缩放、Qt Y向下的显示缓存，不能混用三个输入。旋转、居中和来源父链已经参与原生投影；在上述换算之外再施加会错位。FreeCAD1.1.0与1.1.4的相关getter、翻转和PathBuilder主源相同；这项主源核对不代替其它构建的原生验收。

整页障碍需要有界、完整的缓存读取和索引绑定。现有`inspect_drawing_page`的单个窗口没有可确认总数，不能当成全页；可借鉴已有限制的缓存枚举及指纹保护，但不因读取两次相等或对象Up-to-date就声称HLR完成。几何缺失、超限或状态未知时停止建议，不主动重算、等待事件或自动重试。

纸边取模板宽高；原生`sceneRect()`包含额外页外空间，不能当可打印范围。已识别A4草稿可沿用保守的下部保留区策略，但必须绑定实际模板和区域合同，不宣称所有同名或自定义图框的标题栏都相同。

## 标签范围与原生接口限制

FreeCAD已有默认放置和链式/阶梯排列逻辑，可借鉴边中点、统一方向及字号间距。已有命令会修改选中尺寸并开启事务，不能在只读prepare中调用，也不能借此改变用户选择。

`DrawViewDimension.getRect()`并非标签范围，原生实现返回固定小矩形。实际GUI标签由主值、单位、容差等子项组合，X/Y对应标签中心；字号按大写字母高度换算，不是简单的点数或固定DPI。Qt文字advance也不等于实际绘制范围，斜体、符号和字体替代需要考虑。

已有尺寸可在严格引用与类型核对后读取原生格式文本，但新尺寸在prepare时不存在。不得为量文字而创建临时CAD节点。首版应落实有限文字格式/单位/字体profile的纯度量与保守余量，再与原生实际标签范围对照；未覆盖设置阻断自动模式，不擅改全局单位、字体或用户标注来让建议通过。已有尺寸若无法取得完整范围，同样不能静默忽略。

计划图必须把估算框明确画出，同时列明原生实际渲染待用户复核。若后续要求提交前逐像素一致的原生预览，需要另行解决无临时CAD写入的原生排版入口；本方案不把估算图升级成这项保证。

## 候选位置与碰撞规则

纯算法采用确定性、有上限的候选搜索，建议顺序如下：

1. 将全部固定障碍转成纸面坐标，先加入本批显式坐标的标签框和线条；规范化请求保持稳定顺序。
2. DistanceX在上/下水平层选位置，DistanceY在左/右垂直层选位置；Distance沿实际投影直线法向两侧选位置；Radius/Diameter在圆外多个象限选位置，同圆的两类标注分层。
3. 初始距离和层间距依据已冻结字号、标签高度、箭头及线宽，并设置纸面毫米下限。可按短尺寸靠近几何的规则排序，以请求顺序或Edge编号稳定打破平局。
4. 对每个候选检查纸边/保留区、其它视图、已有标签、本批已定标签及线条，按偏移长度、交叉与拥挤度评分。预算耗尽等同未找到可验证建议，不扩大搜索或接受最后一次碰撞。
5. 明确区分标签框重叠、尺寸线/引出线交叉及必须接触自身引用边的情况。不能用仅检查文字矩形来宣称整条尺寸线避让完成；未能精确建模的原生线条必须在预览中显示限制。

不自动调整视图、图纸比例、字体或已有标注。无可行候选时标明纸外、保留区、障碍冲突、范围未知或预算不足，由调用方改显式位置或另行调整页面后重新预览；旧token不继续沿用。

## 预览、确认与失效

预览同时给表格和只读布局图：页幅/坐标、全部视图轮廓、已知保留区、固定旧标注、本次引用边、五类新标注、建议中心及估算框。被阻断项和未建模限制可见，不能只显示几个X/Y数值让用户猜排版。图形控件不改变原生选择，不打开或重排CAD图页，不把估算图当成已输出的PDF。

同token绑定原始请求、冻结输入、建议结果和预览。来源/Tip/父链、页面/视图身份、比例位置、投影缓存、模板/保留区、旧标注或字体单位设置发生变化，旧计划失效；请求批准、原生点击和写入前均重验。修改建议必须产生新的完整计划，不能在确认时悄悄再排一次。

用户在原生面板确认后，只新增本次尺寸及其页成员，沿用单事务、局部重算和原生引用/量值/坐标回读。取消不写入；失败或结果未知不自动重发。已有尺寸、来源和文件保持，不保存CAD。成功表示本次关联尺寸按冻结位置创建，不表示投影新鲜、图纸尺寸齐全、制造审签或PDF导出完成。

接入写链时还须反验每个新尺寸的实际ViewProvider字体、字号、线宽、箭头及格式样式与冻结输入一致。`verify_defaults`保护默认值、资源和原有图形，有意排除新增尺寸的图形子树；既有尺寸写器的引用、量值与X/Y回读不能代替新外观反验。观察器或原生修正使新标签样式不同，应按事务归属处理失败，不能继续报告布局验证成功。

## 分阶段实施

| 阶段 | 可交付范围 | 进入下一阶段的条件 |
| --- | --- | --- |
| 输入与合同 | 兼容显式模式；新增能力、严格自动行、冻结布局输入与固定错误；纯算法接普通数据 | 坐标换算、候选确定性、预算、无解和旧模式回归通过；prepare零CAD写入 |
| 五类建议与计划图 | 有限A4图框/样式、同源1–3视图、五类尺寸及固定旧标注避让；完整建议图和冲突原因 | 五类及混合请求均能预览；未知模板/文字范围不伪装成功；确认前的全部输入可重验 |
| 原生闭环 | 同token原生批准、真实标签范围对照、取消、失败、单次撤销/重做 | 按来源、比例、单位字体和拥挤情况逐项建立原生证据；继续明确估算与实际差异 |
| 后续扩展 | 更多图框、单位/容差格式、复杂页面和交互调整 | 每次扩展独立声明支持范围、算法输入及验收；不以基础样例通过推定全部支持 |

实施应拆分纯布局算法、原生输入适配、TS/Python合同与业务绑定、只读预览UI；不把Qt或CAD调用藏入纯算法。详细图形输入留在有界私有计划，公开结果延续有限普通DTO和现有状态预算。此阶段不实现批量PDF/DXF、自动选尺寸或任意已有标注重排。

## 原生验收要求

- 五类尺寸均覆盖，包含同边不同线性类型、同圆Radius和Diameter；不能以单一类型通过代替整组。
- 独立Part::Feature及Sketch→Pad→Pocket Body、原生父链与旋转Placement；核对来源、Tip及几何保持。
- Scale 1、0.5、0.1、0.05分别验证，纸面间距不随模型比例错误缩放，原生测量毫米值不变。
- 小图、大图、细长件、多个视图、已有标注、标题栏附近及纸边；无解时整批阻断，旧标注和显式坐标不变。
- 字体替代、直径/半径符号、长数值、单位方案、locale和容差；实际原生标签范围与估算框对照，未知设置明确拒绝或保持待验，不只核节点数。
- 预览后移动视图、改比例/来源/Tip/父链、模板、字体单位或旧标注，旧token失效且零新增；完整缓存相同也不升级投影验证状态。
- prepare、取消、过期和失败不自动创建或重试；正常确认只有本批新节点，单次Undo/Redo不影响来源与旧标注，不保存文档。
- 原生图页首次打开和后续绘制后检查实际位置、标签与线条；自动化控件验收不代替用户批准，不把布局可读性当制造图完整性。

公开文档只记录通用合同、限制和验收范围。独立运行材料、模型、图像、实际路径和使用讨论不进入本方案或通用源码包。

- [索引边的未缩放/Y反向转换](https://github.com/FreeCAD/FreeCAD/blob/1.1.4/src/Mod/TechDraw/App/DrawViewPartPyImp.cpp#L851-L928)、[实际翻Y实现](https://github.com/FreeCAD/FreeCAD/blob/1.1.4/src/Mod/TechDraw/App/ShapeUtils.cpp#L225-L255)：原生getter是Y向上，公开DTO在reader边界再归一为已声明的Qt Y向下；引用坐标、纸面位置及模型量值必须分别处理。
