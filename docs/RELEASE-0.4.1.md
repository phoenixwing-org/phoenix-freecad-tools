# Phoenix FreeCAD Tools 0.4.1

**状态：待发布，候选试用与发布点检进行中。最后已发布版本仍为0.3.2。** 0.4.0是先前候选，本次使用0.4.1区分；同一未安装开发批次不逐次升号。源码、原生验收、用户试用、安装、GitHub Release与npm Registry分别核对。

## 相对0.3.2的主要变化

- 增加受控的TechDraw图纸创建、关联尺寸与布局能力，提供默认图纸自动标注及单页PDF导出确认链。模型修改、图纸创建与文件输出分别预览和确认，不自动保存CAD。
- 当前文档工具增加缓存尺寸的用户单位显示、对象位姿和导出建议；改进窄面板、长名称、缩略图透视构图及状态恢复。macOS不使用已知会导致Coin离屏捕获崩溃的路径。
- 完善官方Codex登录、代理传递、CLI版本兼容和聊天进程生命周期。错误文字可选中，复制使用小图标；聊天和文档面板共用同一小工具条，统一调用已注册FreeCAD命令。
- 工具菜单提供Phoenix常用子菜单；工作台一级菜单可选，默认隐藏。开发窗口显示实际插件版本、用途和端口，保留原生文档标题。
- 完善多实例登记和目标身份绑定。完整MCP为28项，明确开启实例发现时为30项；内嵌聊天为受控22项。可选Desk扩展分别启用，不因旧Node服务缺工具而静默降级。
- 增加AI可读的发布点检表，统一Git归档、隐私与实际制品审查、GitHub Release和npm回读流程。

## 安装与兼容

Addon ZIP安装Python工作台，不自动替换Node MCP配置。聊天工具模式需配套本版Node服务及Node.js 22或更高版本；配置来源和实际清单分别检查。

明确支持Codex CLI 0.160.0及0.167.0-alpha.3.2。FreeCAD桥接协议保持v1，不自动迁移聊天登记，不接管未知进程，不读取或复制默认客户端的凭据与历史。
