## 读取与只读设计诊断合同

四种读取 `get_document_info` / `list_objects` / `get_object_info` / `inspect_design` 可核对文档实例和部分事件修订。它们不证明缓存新鲜、事务隔离或几何正确；读取不隐式重算，写入继续依靠业务完整快照及事务。能力参数更新后，既有Node子进程可能保留旧schema，需重新连接获取。

`inspect_design` 已实现 Body Tip/成员、对象缓存状态、有限特征参数与表达式、草图几何数/自由度/全约束、零基约束分页。默认每页50、最多100；`getDriving`、`getActive` 和 `getDatum` 独立保留状态/来源，量值使用八维内部单位（角度deg）。未知不是0、false或空清单；PropertiesList读取失败不能伪装为“没有参数”。Link不沿来源，读取不碰Shape、文件路径、求解或重算。

文档实例与partial事件修订延续读取合同；跨页可要求同实例/观察修订，不能据此承诺完整并发保护。完整结果128KiB超限拒绝，不裁剪为成功。新能力不提供旧插件降级；聊天基础配置与清单须对应19工具，启用可选Desk时另核对增加的5工具；只读诊断不引入任意脚本或设计写入权限。

待验要求：

- 用独立人工fixture核对Body/特征、草图、0/false/空值、约束分页、单位及独立驱动/活动状态，并比较读取前后的文档、选择、相机和编辑状态。
- 分别覆盖参数已改但缓存未重算、undo/redo后的旧revision、同Name新文档的旧instance和磁盘文件重开；逐项记录范围，不相互代替。
- 检查读取作用域内的修改、重算与保存；诊断追踪的范围和无法观察的内核行为须明确。
- 聊天验收分别记录精确工具清单、工具事件、原生结果以及缓存/未知语义，不以助手文字代替结果。

## 缩略图与输出合同

当前源码提供独立缩略图页和当前活动文档可见三维内容的预览，默认512×512，可选分辨率/背景。Markdown/PNG文件选择器对已保存CAD建议同目录/stem，未保存文档提供清洗后的文件名，输出位置仍由用户选择。预览不按对象表勾选过滤，不截图桌面或图纸。

待验要求：

1. 可选轴测＋Fit只用于本次图像，并完整恢复原相机。分别覆盖正常、异常和不支持相机，检查CAD、选择、显隐、材质及全局偏好；不通过临时外观写入制造dirty标记。
2. 校验PNG尺寸、压缩/解压预算及结构，移除作者、标题、文本、EXIF、时间和未知附加块，保留像素与必要色彩/透明信息。原生输出需用人工fixture核对，不能只验证合成PNG。
3. 只导出用户已预览的同一份bytes。取消不写；新文件不覆盖并发创建，已有目标须明确确认并重校指纹；不保存FCStd。
4. 覆盖普通/透明背景、正交/透视相机、渲染异常、目标失效与文件冲突；目视核对人工模型构图与相机恢复，并单独记录系统文件选择器的人工交互。

专用浅灰渲染和嵌入FCStd缩略图后续处理：前者需不留下材质/dirty变化，后者涉及工程写盘，必须显式保存确认。当前PNG预览不等于完整风格/工程缩略图能力完成。

## 外观与属性汇总合同

源码提供只读材质诊断、完整修改预览、明确应用和默认取消；透明度支持数值框/滑条，参数变化使旧预览失效。预览会即时写入外观，确认提交既有预览事务；取消恢复以事务归属、快照有效且无外部污染为前提。Link本地/来源报告分开，报告不等于最终像素验收。五个正式字符串属性进入信息/Markdown，区分类型、缺失、空值、裁剪与来源，读取不初始化或沿链接代写。

待验须覆盖逐面材质、不同透明度、完整快照、单文档事务、取消/失败恢复及undo/redo，并检查Link来源保持。扩展属性类型和BOM聚合时继续区分available/empty/missing/unsupported/read_failed，不把缺失或异常伪装为空值。

### 有限参数编辑：首个Pad的Length

源码已将单侧固定Length编辑接入既有`prepare_part_changes`，不增加工具名称。独立`pad_length_write`能力精确门禁、完整typed快照、原生人工确认、单事务、一次局部重算及几何反验已有实现和合成测试；尚未执行此链的原生验收，也未部署。仅支持一个打开文档、一个Body的首个且最终Pad、未附着identity草图和+Z方向等有限条件，详见[Pad编辑合同](PAD-LENGTH-EDIT.md)。直接apply始终拒绝Pad。

按FreeCAD 1.1.0官方实现核对后的合同：

- [FeatureExtrude](https://github.com/FreeCAD/FreeCAD/blob/1.1.0/src/Mod/PartDesign/App/FeatureExtrude.cpp)的SideType区分One side、Two sides、Symmetric，不能仅用旧Midplane=false判断单侧。计算还会更新Direction和属性可写状态，不能要求所有耦合属性完全不变。
- [Pad](https://github.com/FreeCAD/FreeCAD/blob/1.1.0/src/Mod/PartDesign/App/FeaturePad.cpp)的Type=Length与SideType应分别校验；原生Length允许负值，本工具独立限制0.01–10000的有限正数/mm范围，不能依赖宿主拒绝。表达式控制、外部引用或未知配置先明确拒绝，不能覆盖表达式来凑成功。
- [Document.recompute](https://github.com/FreeCAD/FreeCAD/blob/1.1.0/src/App/DocumentPyImp.cpp#L675-L723)返回整数对象计数，不能把真值当几何成功。必须另验目标及Body状态、实体有效性/数量、有限尺寸与体积，并明确重算范围。

Body.Tip是目标Pad仍不证明依赖范围封闭：其他Body、表达式、Link或TechDraw可能依赖它；整文档重算也可能执行其他已Touched对象和FeaturePython。当前实现严格枚举11个受支持原生对象和内存依赖图；附着草图、额外消费者、Link、其他特征、Python对象及未知配置均返回不支持，不尝试整文档重算。该范围不承诺隔离未知原生观察者或同事务回调。预览只陈述输入/原值/将执行的动作，不伪造尚未计算的几何预览。

事务数字ID只能防止关闭另一ID的操作，不能证明同ID内没有第三方同步修改。预览token须绑定原生文档/对象实例、Body/Tip、完整相关配置、表达式与依赖快照；确认后重新核验。提交/回滚结果不明时不重试关闭，更不能自动保存。原生公开fixture仍须有独立配置、明确授权，以及错误/取消、undo/redo与未保存状态证据。

## 聊天与Desk

聊天采用独立专属会话，源码提供官方服务 `model/list` 目录读取、模型选择和字号偏好。模型ID和字号分别持久化；模型目录/选择受连接和会话阶段限制，聊天开始后不提供热切换。字号应用于聊天记录与输入框，0继承宿主字体、8至32为显式字号；设置不应自动重置已有聊天。待验需分别核对显式字号/继承、偏好读回、当前连接的目录选择及实际型号，目录结果只适用于对应授权范围。

聊天的Label/BOM/Link完整预览、原生确认与状态查询已有源码，原生端到端验收仍待；有限Pad参数编辑源码已接入同一确认链，原生验收及更广模型范围仍待；会话恢复和其他设计写入继续列为后续能力。详见[原生确认链](NATIVE-PART-APPROVAL.md)。共享用户管理app-server与接管当前Codex Desktop会话分开研究；缺少受支持endpoint/线程订阅合同的能力保持待研究，不读取私有socket、auth、cookies或历史。新增MCP能力按清单、参数、工具事件和CAD结果分别验。

Desk复杂能力通过明确连接的后台/Web交接，简单且适合内存的能力留工作台。先明确版本化Release资产、平台/Node需求、内容manifest、摘要和服务身份，再实现用户点击下载/安装。未知服务/状态目录不接管、不换namespace绕过、不按PID停服。Wing复用先核正式cad-core/cad-contracts导出，不写本机file/link依赖或复制Web UI进Qt。
