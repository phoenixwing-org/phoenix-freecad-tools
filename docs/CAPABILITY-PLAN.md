# 零件与图纸设计能力计划

日期：2026-10-24。目标是让聊天客户端理解当前 FreeCAD 设计，完成参数化零件与 TechDraw 图纸的常用工作。先实现 FreeCAD 原生能力，Phoenix Tool/Wing 业务集成后置。以下未完成项都是计划，不是已注册工具。

## 实施顺序

| 阶段 | 目标 | 交付与验收 |
| --- | --- | --- |
| P0 已完成 | 打通客户端与 FreeCAD | 安装、启停、能力发现、状态、文档列表、fit、轴测，见 [验证记录](VERIFICATION.md) |
| P1 优先 | 看懂当前零件与图纸 | 文档、对象树、属性、选中项、测量、当前视图与图纸结构，解释已打开的公开样例 |
| P2 | 参数化零件 | 带事务的 Body、草图、约束、拉伸、切除和参数修改，演示带孔连接板，保留可编辑特征树 |
| P3 | 工程图 | 页面、模板、标准投影、比例、基本尺寸、图框字段，输出 PDF/SVG，在副本重开验收 |
| P4 | 扩展设计覆盖 | 倒角/圆角、旋转、镜像/阵列、Link 放置、剖视/局部视图；按真实案例逐项增加 |
| P5 后置 | 现有 Tool/Wing | 命名规范、批量图纸检查、任务与业务规则复用，工作台按钮和 MCP 共用实现 |

内嵌聊天保留为独立调查项，见 [路线图](ROADMAP.md)，不阻塞 P1 至 P3。

## P1 先取得设计上下文

第一批计划新增以下 8 个工具，每个接口限定返回字段和数量，避免把整个工程一次性传给聊天客户端。

| 拟定工具 | 返回内容 | 设计用途 |
| --- | --- | --- |
| `get_document_info` | Name/Label、文档实例标识、修改状态、单位、活动 Body、重算与错误状态 | 明确目标及未保存修改 |
| `list_objects` | 分页对象树、TypeId、Name/Label、Body/Tip、依赖与可见性 | 理解特征顺序，找到草图、实体和页面 |
| `get_object_info` | 指定属性、表达式、Placement、特征输入；草图几何/约束/自由度；Link 来源、实例路径和变换 | 理解参数、草图状态和装配引用 |
| `get_selection` | 所选对象、面/边/点及所属实例 | 让“这个面”“这条边”有可核对的指向 |
| `measure_geometry` | 包围盒、长度、面积、体积、几何重心、圆/圆柱半径及指定几何间距离 | 核对尺寸和孔径，区分局部与装配坐标；质量需另有密度依据 |
| `capture_view` | 当前 3D 视图或指定图纸页图像，限制分辨率和大小 | 看操作结果；默认不旋转、不 fit、不写持久文件 |
| `list_drawing_pages` | 页面、模板、纸张、比例、视图与尺寸摘要 | 理解已有工程图 |
| `inspect_drawing_page` | 视图来源、方向、位置/比例、图框字段、尺寸引用与已知错误 | 找出缺失来源、失效引用和布局疑点；检查不自动修复 |

随后补 `set_view`（标准正视/俯视/侧视）、对象显隐、选择/高亮及 `validate_document`。校验区分“现有错误状态读取”和“执行重算/几何检查”，耗时检查单独报告。现有 `fit_view`、`set_axonometric_view` 保持可用。

P1 验收：从已打开的公开连接板读取对象树、主要尺寸、孔相关几何和图像，说明数据来自哪个文档/对象及何时观察。用带 App::Link 和 TechDraw 的公开用例核验引用链，不保存、关闭或修改模型。

## P2 参数化零件最小闭环

| 能力 | 拟定接口 | 首批范围 |
| --- | --- | --- |
| 新文档与 Body | `create_document`、`create_body` | 在新文档演示，不覆盖已有文档 |
| 草图 | `create_sketch`、`edit_sketch` | 明确基准平面或支撑；线段、矩形、圆、圆弧；水平/垂直、重合、对称及尺寸约束 |
| 实体特征 | `create_feature` | 首批仅白名单 Pad/Pocket，规定 Profile、长度、方向和贯穿语义 |
| 参数修改 | `edit_parameters` | 只允许声明的尺寸、约束和表达式字段，不开放任意属性写入 |
| 重算与校验 | `recompute_document`、`validate_document` | 草图求解、Body/Tip、实体数量、空形状和几何有效性，返回失败对象 |
| 修改结果 | `get_operation_status`、`undo_operation` | 查询结果；只撤销仍在栈顶的本项目指定操作，保护用户后续编辑 |

草图、特征和参数接口允许有明确类型的批量操作，以一笔短事务完成一个设计步骤，避免逐条约束造成过多往返。任意 Python 执行不作为实现这些能力的前置条件。

P2 演示：新建 60 × 40 × 6 mm 连接板，4 个直径 6 mm 通孔，孔心相对板中心为 `(±20, ±10) mm`。使用真实草图、尺寸约束及 Pad/Pocket，将厚度改为 8 mm 后重算，核对包围盒、体积和孔几何。草图自由度为 0，无冲突/冗余约束，最终是一个有效实体。体积以 `(2400 − 36π) × 厚度` mm³ 解析核对，误差不超过 `max(0.001 mm³, 预期体积 × 10⁻⁶)`。能在 FreeCAD 手动继续编辑；默认不保存。失败回滚和一步撤销针对单个建模步骤，不承诺撤销整个多步骤演示；新建文档不属于普通文档内事务，不自动关闭。

## P3 TechDraw 常用出图

| 能力 | 拟定接口 | 首批范围 |
| --- | --- | --- |
| 页面与图框 | `create_drawing_page`、`update_template_fields` | 使用指定模板，设置纸张、比例和模板真实提供的字段 |
| 标准视图 | `add_drawing_views`、`update_drawing_view` | 正视/俯视/侧视和轴测；明确第一/第三角投影、方向、比例、位置与来源 |
| 尺寸与标记 | `add_drawing_dimension`、`add_drawing_annotation` | 先做线性、直径/半径、孔中心线与文字；尺寸绑定可核验几何 |
| 检查与调整 | `inspect_drawing_page`、`validate_drawing_page` | 来源及尺寸引用、重算状态、纸张边界、视图/标注遮挡疑点；调整需显式操作 |
| 导出 | `export_drawing_page` | 明确页面、PDF/SVG 格式和目标文件，验证尺寸及实际渲染 |
| 保存与交换 | `save_document_as`、`export_model` | 独立文件写入规则；模型先支持明确对象的 STEP，保存与导出分开 |

P3 演示：从 P2 零件生成 A4 图纸，含标准投影和轴测、长宽厚及孔径基本尺寸、图框字段。检查后导出 PDF/SVG；在测试副本保存并重开，确认图框、模型引用、尺寸和缩略图保留。既有图纸先检查，再按用户授权范围修改，保留手工排版和注释。

独立图纸及外部 Link 需专门用例：区分零件定义与装配实例，正确处理来源和 Placement，不默认打散为静态几何。剖视、局部放大、完整公差/粗糙度及自动尺寸布局在 P4 分项验收。

## 写入能力的共同前置工作

- 明确目标文档 Name、文档实例、对象 Name 与预期类型；写入不依赖活动窗口或 Label。
- 几何参数带明确单位，区分长度、角度和比例，拒绝非有限数值。面/边引用附来源与几何校验，模型变化后拒绝失效引用，不猜接。
- 为读取的文档状态建立校验标识；应用前发现用户已修改则重新读取。预览列出对象、参数和影响，已获授权范围内执行，超范围再确认。
- 状态校验与实际应用放在同一次 GUI 执行步骤内；遇到模态窗口、草图/任务编辑或其他未完成事务时拒绝或明确等待，避免干扰用户操作。
- 每个修改步骤限定单文档、一笔命名事务；重算及检查成功才提交，失败回滚。先支持经验证能回滚的原生操作，跨文档修改单独规划。
- 增加 operationId、重复请求识别和结果查询。执行超时不证明操作已回滚；已开始的写入不自动重试，重连先查状态，不能证明结果时报告未知。
- 保存、导出、导入采用独立文件规则：明确来源/目标、受控目录和格式；覆盖按授权处理，事务回滚不代替磁盘备份与临时文件清理。
- 写入默认只改变内存文档，不连带保存或关闭其他文档。GUI 操作仍进入 Qt 主线程，长任务单独查询状态，一次事务不跨多轮聊天。

## 工具扩展与命名

按设计任务增加稳定 MCP 工具，不逐个复制 FreeCAD 所有菜单命令，也不把操作塞进无类型通用命令。接口使用动词加对象，参数采用明确 schema；中文版标题和描述帮助发现能力。

能力分组规划为 `document`、`selection`、`view`、`geometry`、`part_design`、`techdraw`、`file_io`。`get_capabilities` 后续返回实际实现的分组、版本、可用状态与副作用，未实现项留在计划中，不向 AI 宣称可调用。新增工具同时更新 MCP 注册、Python 白名单、协议、能力清单、测试和使用示例。

工作台业务按钮使用 `PhoenixTools_`，共享业务实现分别提供 GUI 和 MCP 入口；按实际需要决定是否显示按钮，fit/轴测无需重复示例按钮。整体项目采用更宽泛名称的方向见 [命名](NAMING.md)。

## 每批交付要求

每次交付一个可演示的小闭环，使用公开或新建测试文档。除协议与参数测试外，在真实 FreeCAD 检查几何/图纸结果、错误回传与未保存修改保护；支持保存时增加副本重开验收。未执行的检查不得记为通过。

最先实施 P1 文档/对象/选中项读取，再补测量和图像；同时定义 P2 事务与操作结果协议。Tool/Wing 集成排在 P5。

FreeCAD 原生接口核对入口：[Document](https://freecad.github.io/SourceDoc/d8/d3e/classApp_1_1Document.html)、[TechDraw DrawPage](https://freecad.github.io/SourceDoc/d9/d5a/classTechDraw_1_1DrawPage.html)。具体参数和行为以目标版本实现及真实用例验收为准。
