## 下一轮小闭环

1. [ ] 在独立配置和人工CAD中验收外观预览、取消/关闭、事务归属、撤销与重做；保留现有用户文档及服务。
2. [ ] 有限首个Pad Length的typed快照、原生确认、单事务及一次局部重算反验已有源码/合成测试；按[合同](PAD-LENGTH-EDIT.md)继续独立原生验收、撤销重做及范围扩展，不自动保存。
3. [ ] 聊天Label/BOM/Link完整预览、原生确认和状态查询源码已接入；继续独立原生验收及有限参数写入；不以文件只读沙箱代替MCP写权限控制。
4. [ ] 插件自有聊天恢复先明确持久化、单writer、退出确认和事件去重；桌面当前会话共享另核正式接口，不读取默认凭据或聊天库。
5. [ ] Desk按正式版本和运行态合同提供索引/缓存共享，再经Web会话及统一未保存确认合同接工作空间导航、可追踪构建/导出和预览后批量修复；ready不授予Native执行权限。
6. [ ] 正式发行前重新打实际包并核对隐私、许可、摘要、恢复与宣称平台；外部或平台条件不足的项目保持待办。

## 文档与数据共享

- [ ] 常规标量、枚举及常用量值已有只读源码；继续原生验证、列表等类型和显示单位转换。Link不显式解析来源，0/false/空值、缺失、嵌套读取异常与截断分开表达。
- [ ] 浅灰渲染先独立核对变换、法线、隐藏子面、透明度和Link；不以上层材质覆盖代替有效渲染。
- [ ] 制造特征统计区分文件hash、内存修订、统计语义和实际发生数，未知保留，不直接读取或修改Desk数据库。
- [ ] 同一快照的全图册分页和完整性；来源失效不静默回退，不能把缓存或索引当实时CAD。
- [ ] 工作空间导航作为独立写操作；资料元数据、文本索引和按页/段精读分别定义显式目录、类型、hash与定位。
- [ ] 下载/安装/编译/启动分别授权；固定平台资产、摘要、依赖、许可与数据迁移合同齐全后再做向导，不接管未知服务或换namespace绕过。

## 验收与隐私约束

改名和属性先完整预览再确认；写入复核完整相关快照，逐setter及提交前检查事务数字ID。提交/回滚结果不明时停止，不重复关闭或碰外来事务。相机/选择/材质恢复须分项验收，不保存用户CAD。实例及部分事件修订只用于可观察的旧读拒绝，不等于完整并发或缓存新鲜度保证。

公开材料只保留通用能力、官方来源及独立中性fixture；私有项目、讨论、真实使用过程和去标识摘要不得进入Git或包。历史运行回执不随源码分发，旧分支/标签/归档须独立审查，不把当前树干净说成全历史净化。参见[隐私边界](PRIVACY-REVIEW.md)及[验证与验收](VERIFICATION.md)。
