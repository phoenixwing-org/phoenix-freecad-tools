# 后续任务

当前版本为 0.2.1。本表把已实现与待办分开；最终真实验收和测试数量见 [验证记录](VERIFICATION.md)，能力范围见 [能力计划](CAPABILITY-PLAN.md)。

## 本轮已实现与已实测

- [x] 16 个 MCP 工具：能力/连接、文档与对象读取、选择、测量、图纸检查、相机、三维截图和高级脚本状态。
- [x] 脚本会话 ID、请求去重、状态查询、结果与历史容量边界。
- [x] 参数板：60 × 40 mm、4 × Ø6 mm 通孔，全约束草图与 Pad/Pocket，厚度 6 → 8 mm 后校核。
- [x] 已知参数样例的 STEP 导出、导入与参数化重建对比；不包括任意 STEP 自动恢复历史。
- [x] TechDraw 四视图与 6 mm 几何关联孔径尺寸；PDF/SVG/PNG/FCStd 导出、独立重开和缩略图检查，最终 PDF 布局目视验收通过；非生产图纸审签。
- [x] Phoenix Tools 工作台、普通工具 MVC 和带图标/状态文字的单按钮 MCP 启停。
- [x] 另一聊天只读联测；本机旧桥接停用备份并移出加载目录、旧 Codex 服务条目移除。

## 普通工具与业务复用

- [ ] 按实际任务扩展正式属性与命名规则，继续保留预览、来源、冲突和撤销边界。
- [ ] 对稳定普通工具增加 MCP 入口时复用同一 Model/Controller，避免两套业务规则。
- [ ] 普通对象需要保持 Label 唯一时，支持有序批量改名和名称互换：先用临时唯一名称过渡，再应用最终名称；先检查最终冲突，整体预览与回滚。当前遇到冲突直接拦截，不静默加序号。Link 与来源需最终同名，继续使用事务内临时允许重复并还原设置的方案。
- [ ] 文件/目录批量命名另行设计引用检查和恢复流程；当前 Label 工具不承担文件改名。
- [ ] 大型 Tool 经公共 TS 包或正式 HTTP 适配；下载、编译、自动启动和版本管理后置。
