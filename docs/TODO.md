## 语言覆盖与工具扩展

- [ ] 可选跟随 FreeCAD 界面语言；目前仅明确中文/English，不修改 FreeCAD 全局语言。
- [ ] 为动态 Model/Controller 校验和原生错误建立可复用消息合同；当前可能保留原文，设置中已说明。
- [ ] 按实际需要完善正在编辑的对话框语言刷新，保留用户输入；当前新打开的对话框采用所选语言。
- [ ] 普通对象的有序批量 Label 改名和名称互换：先检查最终冲突，再用临时唯一名称过渡，整体回滚；当前冲突直接拦截，不静默加序号。
- [ ] 文件/目录批量命名另行处理引用与恢复；当前 Label 工具不承担文件改名。
- [ ] 扩展正式属性模板及更复杂业务，继续复用同一规则和 Controller，保持差异预览。
