# Phoenix FreeCAD Tools 愿景

把 Phoenix Tools 建成可独立安装的 FreeCAD 工具工作台。人工按钮与聊天逐步共用能力：先理解当前文档，再执行明确操作，给出几何、图像和文件结果。0.2.0 的实际交付见 [README](../README.md)；以下是继续扩展的方向，不代表全部已实现。

## 人工工具与聊天协作

现有命名、正式属性填写和 Link 名称同步作为普通 GUI 工具独立使用。后续聊天入口复用同一规则和 Controller，继续保留差异预览、来源、冲突、事务及撤销边界。文件和目录批量改名另行检查引用，不把当前 Label 修改扩大为文件重命名。

缺失链接扫描与修复将覆盖外部文档、App::Link、图纸来源和模板：列出候选和映射，存在版本或同名歧义时交由人工决定。独立图纸维护需保留手工排版、图框、标注和缩略图，副本重开后验证结果。

## 设计与图纸

常用操作使用有类型工具，高级任务保留显式原生脚本，逐项验证参数化特征、可编辑性和恢复能力。已知参数的 STEP 重建继续扩展为受控几何识别案例，不承诺自动恢复任意原始设计历史。

TechDraw 从已通过验收的公开四视图演示扩展到更多投影、关联尺寸、剖视/局部视图、图框和导出。完整尺寸、公差与自动排版分别验收，不以单个示例替代生产图纸检查或审签。

批量装配从明确清单或 BOM 建立实例与放置规则，区分零件定义和 App::Link 实例，保留数量、层级与变换。零件/版本替换、位姿和属性批量更新需预览引用影响，跨文档写入另行设计恢复。约束装配求解与其他工作台兼容独立调查，不把简单摆放视为约束装配。

## 界面方向

简体中文 / English 切换仍是 TODO，未来采用统一翻译资源与本机偏好，不改变 MCP 或脚本技术标识。

内嵌聊天先调查复用本机客户端与现有会话的官方支持路径；当前没有内嵌面板。会话 ID、消息与登录状态留在本机，不进入公开代码。调查范围见 [路线图](ROADMAP.md)。

## 业务适配与分发

小型正式规则保留来源和许可；大型业务通过公共 TS 包或正式 HTTP 接口接入，避免在 Python 复制整套业务。按需检测和启动服务须有明确位置、版本和进程所有权，只管理插件自行启动的进程。下载、编译、自动启动尚未实现，也不是现有工作台的依赖。

继续维护 Apache-2.0、版权与依赖声明，完善各平台安装、升级、卸载和故障说明。发布前核对公开案例、实际包清单及隐私，分别验证普通 GUI 与 Node/MCP 接入。未来准备独立分发及 FreeCAD Addon Manager 收录；当前没有远程发布或提交收录。
