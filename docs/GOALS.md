# 当前聊天驱动 FreeCAD 的目标

让用户在当前聊天中用自然语言提出操作，由 AI 通过 Phoenix FreeCAD 的 MCP 服务理解和操作已打开的零件及图纸，减少在聊天、Python 控制台和工作台之间切换。优先原生设计能力，现有 Tool/Wing 业务后置。

## 执行里程碑

1. **通用操作闭环**：读取当前文档、对象、选中项、属性、几何和图纸结构；标准视图与模型截图。增加 GUI Python 脚本执行、请求去重和结果查询，使当前聊天能调用尚未专门封装的 FreeCAD API。用已打开公开零件实测，保护其他文档。
2. **参数化零件设计**：根据尺寸创建/修改可编辑 Body、草图、约束及特征，重算与测量验证；常用步骤逐步封装。演示带孔连接板和参数修改。
3. **STEP 参数化**：先读取导入几何、单位、实体及装配结构，识别平面/圆柱/孔等特征；提供直接几何操作、以导入形体为基础添加参数特征，以及重建草图/特征三条路径。STEP 的 BRep 不等于原始特征历史，不承诺自动恢复原设计树。重建结果对比尺寸、体积和几何差异，保留导入来源。
4. **图纸设计**：读取/检查 TechDraw，创建或修改页面、图框、标准视图、比例及基本尺寸，导出 PDF/SVG；保存副本重开验证，保留用户已有排版与注释。
5. **业务与界面扩展**：按需加入工作台按钮、内嵌聊天调查和 Tool/Wing 业务封装，具体范围见路线图。

## 两层接口

常用任务提供有类型的 MCP 工具，便于发现、传参和检查。高级任务提供显式 Python 脚本工具，运行在当前 FreeCAD GUI 主线程，能够操作当前会话文档；长计算后续另行隔离。

脚本拥有与 FreeCAD Python 控制台相同的权限，可以修改模型及访问本机资源，不是沙箱。MCP 不自动附加保存/关闭操作，脚本仍可显式执行这些操作；调用方必须遵守用户授权。失败不代表自动回滚，超时不代表取消；通过请求 ID 查询状态，不盲目重复执行。通用脚本和常用封装共同覆盖任务，不要求逐个包装全部 FreeCAD 命令。

## 验收

- 当前聊天能通过真正的 MCP 工具调用定位公开的已打开零件，读取对象和尺寸、获取模型视图并执行一个明确操作。
- 结果给出目标、数据/图像、修改影响和错误；脚本请求可去重并查询完成、失败或仍在运行的状态。
- 参数化零件、STEP 与图纸分别用公开/新建样例演示，几何与渲染结果可核对；未实现或未验收项目不写成已完成。
- 默认不改动其他工程，不把生产模型、聊天 ID、凭据或个人路径写入开源项目。文件写入、覆盖和关闭遵守具体任务授权。

具体接口、阶段和验证规则见 [能力计划](CAPABILITY-PLAN.md)。执行状态以 [验证记录](VERIFICATION.md) 为准。
