# 讨论与架构决定

更新：2026-10-25。记录当前明确的方向，不复制私有工程信息。当前能力以 [验证记录](VERIFICATION.md) 为准。

## 名称与界面

项目目录为 `phoenix-freecad-tools`，表达持续扩展的工具集合。npm 包/CLI 保持 `phoenix-freecad-mcp`，插件目录为 `PhoenixFreeCADTools`，技术类名为 `PftWorkbench`，Python 模块/测试采用 pft_ / test_pft_，自有类采用 Pft；工作台显示名为 **Phoenix Tools**，GUI 命令使用 `PhoenixTools_` 前缀，完整对应见 [命名](NAMING.md)。

工作台同时提供独立工具和一个 MCP 启停按钮。状态圆点显示运行状态，灰色三角/方块表示启动/停止动作，文字保留在菜单、悬停和状态详情；选择工作台不自动启动桥接。轴测与Fit合为一个常用工具条图标，外观另用一个图标打开紧凑非模态随机色/透明度窗口；文档面板不重复这些大按钮。全部业务图标默认配文字，设置可仅图标，MCP三控件固定图标。中文/English 基础设置已实现，动态业务错误全翻译和跟随 FreeCAD 语言后置。

## Node.js / TypeScript 与 Python 分工

Node 服务使用官方 MCP SDK 向聊天客户端注册工具，便于未来复用 Phoenix Tool/Wing 的 TS 类型、协议与算法。FreeCAD 的模型、相机和 TechDraw 操作经轻量 Python 桥排回 Qt 主线程执行；Node 不代替几何内核，也不依赖模拟点击操作。

应用代码独立实现，Apache-2.0，不从其他 MCP 服务派生。固定接口封装常见上下文和相机能力，显式 `execute_script` 覆盖尚未封装的原生 API；不逐个包装所有 FreeCAD 命令。显式脚本有完整 Python 权限，不是沙箱，失败不保证回滚，超时不代表取消。请求去重和结果查询的会话范围见 [协议](PROTOCOL.md)。

## 普通工具与复用

普通工作台工具按 Model / Controller / View 分离，使用正式字段和可预览、可撤销的事务。小型 BOM 组名规则已从 Apache-2.0 的 Wing 公共规则移植，保留 NOTICE 来源；不引入整个 Tool 服务。Link 属性可能转发至来源，因此属性填写明确拒绝 Link，名称同步仅改所选实例。

离线直接改文件中的 Label 与 GUI 运行时赋值的校验不同：运行时可能因唯一性规则自动加序号。Link 同步通过正常 Label API，仅在事务写入期间临时允许重复并精确还原偏好；写后先核对实际值、直接来源身份和最终重名集合，只允许来源及同来源 Link 重名。失败先整笔回滚再恢复设置，成功检查完成并恢复设置后再提交。离线命名逻辑不能不经验证直接用于已打开文档。以后再次手工改名仍遵循当时的 FreeCAD 设置，内部 Name 不变。普通对象需要唯一 Label 时，当前先拦截最终冲突；名称互换的有序、临时唯一名称过渡另列 TODO，不能用调整顺序解决 Link 最终应同名的要求。

主流程先交付原生设计与图纸上下文、参数化零件和受控演示，再设计稳定结构化写入合同。未来纯 TS 规则与 DTO 经正式公共包复用，任务、数据库等经正式 HTTP 适配；大型 Tool 下载、编译、启动和版本管理后置。面向独立批处理进程的脚本不能直接用于用户有未保存修改的 GUI 会话。保存 XML 或缓存检查不视为当前 GUI 实时状态。

## 演示与许可

历史初版使用外部公开 Study 连接板验证相机，模型未复制，派生图片保留 MIT 声明。当前建模、STEP 和 TechDraw 使用新建人工样例；已知参数重建不等于任意 STEP 恢复历史，演示出图不等于生产图纸审签。

原创应用代码采用 Apache-2.0，完整文本见 [LICENSE](../LICENSE)，组织 Logo 和小型规则来源见 [NOTICE](../NOTICE)。FreeCAD、官方 MCP SDK 及未来引入代码分别保留适用许可和声明。

本阶段仅本地提交、标记与归档，不远程发布；跨平台和 Addon Manager 收录后续另行验收。聊天可由外部客户端或现有独立原生app-server面板管理，不要求Platform API Key；复用桌面当前同一会话仍需调查官方支持方式，见 [路线图](ROADMAP.md)。

## 版本收敛

0.3.1基线后的未推送改进统一为0.3.2候选，不再为每项界面修正或测试升号。0.4–0.10只作历史内部标签，实际运行桥接与Desk产品版本保留，见[版本约定](VERSIONING.md)。本轮最终原生、包及归档由验证记录确认，跨平台与正式发布另行验收。
