# 本地归档隐私审查

日期：2026-10-24。范围：本地原型标签 `v0.1.0` 对应的 Git 源文件、npm 实际打包清单及归档文件内容。审查结合逐文件用途检查、路径/凭据模式检查、依赖地址核验和公开图片目视核验。

命名迁移版本 `v0.1.0-naming.1` 延续本审查，并重新核对新增安装迁移测试、命名文档和实际包清单。旧内部名只在一次迁移识别、相关测试和映射记录中保留，不是运行兼容别名。旧归档和标签保持原样。 新增设计计划只含通用能力及人工构造的公开演示尺寸，没有生产工程、实际聊天 ID 或个人路径。

## 已检查

- 源码、文档、测试和锁文件未发现用户个人绝对路径、用户名、私有工程型号/零件、真实生产模型、私有图框、数据库或凭据。
- `.env`、日志、node_modules、dist、Python缓存和归档自身排除在Git提交之外；`.env.example`只有本机服务地址和超时设置。npm包按精确白名单保留必要dist，不包含本地路径。
- 曾发现Python缓存包含绝对编译路径，已补Git忽略及npm文件白名单；最终归档不含pyc。
- npm依赖地址为公共registry，无URL凭据、本机file依赖或本地Wing指向。dist source map只有相对src路径，没有内联源码或遗留Desk适配代码。
- 测试中的假凭据URL用于验证拒绝行为，SHA/integrity是校验值，不是秘密。
- 图片只显示公开Study连接板，不含桌面、控制台历史、用户工程名称或路径；源模型未复制，展示图保留MIT来源声明。
- 原创代码Apache-2.0，LICENSE与NOTICE已提供；公开样例名属于用户指定的开源验证内容。
- Codex全局配置、FreeCAD安装标记、运行状态文件和本机路径不纳入归档。

## 归档约定

仅进行本地提交、标记、源码ZIP及npm包归档，不推送远端。提交使用非个人的本地自动化作者标识；源码ZIP由Git标签生成，不包含.git元数据。

服务正常使用时，文档列表可能把当前会话文档名交给已连接的AI客户端，这是用户调用该工具的结果；它们不自动写入本项目验收记录或归档。

## 0.2.0 增量审查

新增范围包括结构化读取、显式 Python 执行、视图捕获、MVC 工具、公开人工样例和验收 helper。新增示例只使用人工几何和虚构属性值；未复制用户提供的属性截图，也未使用其中实际零件名称或编号。真实联测输出留在本机临时目录，开源记录仅保留去除路径、会话 ID、外部文档信息和图片 Base64 的公开演示结果。

测试中的 `/Users/private` 是路径隐藏回归的人工输入，不是用户个人路径。源码与包重新检查凭据模式、个人路径、聊天标识、生产模型、缓存及安装状态；公共 npm registry 锁定版本和 NOTICE 中的小型 Apache-2.0 规则来源保持清楚。FreeCAD 自带图框由本机示例引用，不复制到源码包。

`execute_script` 接收并执行调用方明确传入的脚本，有完整本机 Python 权限；它不是隐私过滤沙箱。文档标签、属性、脚本输出或模型图像可能按调用进入已连接的 AI 客户端。框架不自动采集桌面、上传模型、读取 API Key、加入聊天历史或保存用户文件。当前本机桥接无进程身份认证，仅供可信本机环境使用。

本次只在本地提交、打标签和归档，不配置或推送远端。最终包和归档的文件清单及摘要写入本地归档 manifest；不将恢复备份、Codex 全局配置或运行中的请求记录打包。

0.2.1 的改动仅补强 Link 写入后的来源/重名检查和失败回滚顺序，延续相同的隐私与归档规则，不增加数据采集或依赖。

## 0.3.0 增量审查（2026-10-25）

新增选择/显隐/重算和两阶段业务。预览 token 只在插件内存保留，不写配置或模型；公开验收已移除活动 token。仅公开人工属性和模型用于本轮联调，六份原有工程只保存内存基线，不把名称、路径或内容写入仓库。中文/English 设置只写 PhoenixTools 自有语言偏好，不读取账户、登录或聊天历史；机器字段和模型值不翻译。

新文件、实际 npm 包与源码归档重新检查个人路径、凭据、聊天标识、缓存和工程文件。新增测试中的路径与异常文本为人工输入；依赖版本和公共 registry 来源未增加。继续只本地提交和归档，不远程推送。
