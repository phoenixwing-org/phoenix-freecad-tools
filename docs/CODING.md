# 项目代码规范

适用于 Phoenix FreeCAD Tools 的新增代码和实际修改范围。先保持业务语义与宿主边界，再做小步改进；不为风格统一重写无关文件。命名合同见 [NAMING](NAMING.md)，共享边界见 [WING-REUSE](WING-REUSE.md)。

## 命名与模块

- Addon 目录为 `PhoenixFreeCADTools`；自有 Python 模块用 `pft_*.py`，测试文件用 `test_pft_*.py`，生产公开类用 `Pft...`，私有类可用 `_Pft...`。
- Node 包/CLI `phoenix-freecad-mcp`、GUI 命令 `PhoenixTools_*`、MCP 方法、正式 BOM 字段和用户数据是各自合同，不做无语义的前缀替换。
- `Init.py` / `InitGui.py` 和 FreeCAD/Qt 要求的钩子名称遵循宿主。InitGui 保持薄入口，主体放正常模块，不依赖 FreeCAD loader 共用 globals/locals 的偶然行为。
- 动态加载按本模块位置解析来源；复用模块缓存时核对同一来源，来源不明明确拒绝，不调用未知模块的清理代码或静默混用安装副本。

## 职责与线程

| 层 | 职责 | 不承担的内容 |
| --- | --- | --- |
| Model | 纯规则、字段、快照结构与纯校验 | 不 import FreeCAD/Qt，不访问 Shape、偏好、磁盘或服务 |
| Controller | 注入 App/Gui 或 runner，复核目标与状态，组织确认后的事务/异步状态 | 不创建 Qt 对话框，不把界面选择绕过为全局对象写入 |
| View | 输入、预览、确认、只读展示及调用 Controller | 不直接写零件属性、开事务、保存工程或接管后台 |
| 原生/进程适配 | 封装 FreeCAD 读取/GUI 主线程派发或 Qt QProcess | 不把宿主 API、进程生命周期混入纯算法 |

CAD 原生读取与修改在规定的 GUI 主线程入口执行；慢进程用异步 runner，界面不阻塞等待。后台工作不持有并操作 GUI 所属几何包装对象。Qt 信号、对象销毁和回调须考虑旧实例/晚到结果，防止重复定时器或旧状态复活。

## 副作用、进程与状态机

- 操作明确区分读取、配置保存、进程启动、打开浏览器、相机/外观、模型修改及文件输出。Desk 连接面板不自动探测/启动后台，保存配置不隐式执行服务动作。
- 进程只使用程序与参数数组，不拼 shell 命令。限定动作、输入、输出大小与超时；失败保持错误状态，不把 stderr 或不完整结果解释为成功。
- 使用明确的 idle/busy/完成/失败状态；同一操作只允许一个在途请求，晚到或重复回调不能更新新请求。配置变化使旧 ready 失效，打开浏览器前重新验证状态。
- busy 时禁用冲突动作，关闭/取消语义明确。超时不代表已经开始的工作被取消；查询原请求，不盲目换 ID 重做。PID/端口不是停止授权，不强杀未知或借用服务。
- 临时偏好只在必要、短且同步的 GUI 作用域使用，不处理嵌套事件；保存原值与键是否存在，异常时先撤销工具事务，再精确恢复。不得永久修改全局偏好来绕过校验。

## 读取、快照与事务

- 只读入口不隐式重算、求解、保存、选择、激活或打开外部文档。几何查询只在明确范围读取缓存，注明单位、坐标范围、裁剪与新鲜度限制。
- 缺 API、异常、未知缓存或无法确认来源时返回 null/unknown 及原因；不能用 false、零或空列表冒充已确认状态。Quantity 数值与单位须使用同一基准，不能把显示单位配给未换算的内部值。
- 对象以明确文档/内部 Name 和原对象身份定位；不根据显示 Label 猜测对象。实例令牌检测内存实例变化，部分事件 revision 仅作读取诊断，不能替代业务写入快照。
- 写入先完整展示目标与差异，确认后复核活动文档、对象、快照、编辑与事务状态；失败整笔 abort。写后验证实际 Label/属性与目标集合，原生自动编号不能报告成功。
- Link 实例与来源分开：不隐式沿链猜来源或转发属性写回源；允许同名的规则必须按来源身份限定，不能仅比较 Label 或扩大到其他对象。
- 文件路径由用户明确选择，输出前说明覆盖与清理范围；不静默保存工程。文档 undo 不代表磁盘文件、后台进程或偏好自动恢复。

## TypeScript 与接口合同

保持 TypeScript `strict`，对外输入用严格 schema 拒绝未知字段、错误类型、无界数组/文本、非有限数值和不安全整数；读取响应也校验实际输出。内部可信类型不能替代跨进程边界验证，不用 `any` 或类型断言掩盖未知数据。

JSON 输出按 UTF-8 字节、项目数量和深度设预算，裁剪须明确；完整预览超限应拒绝，不能截断后继续允许写入。错误使用稳定 code 和清楚说明，不返回原生 traceback、账户信息或本机敏感路径。用户明确选择的本地配置可保存在自有偏好，不能提交到仓库或公开回执。

工具声明须与实际副作用一致；能力清单、已加载版本和协议分别核对。成功请求重放可返回历史结果，但不重复修改或把历史摘要冒充当前状态；旧插件不支持的新能力明确降级或拒绝，不虚构保证。

## Wing 复用与验证

Wing 公共 API 保持 Pnw/pnw/PNW_，本项目只命名自己的 Pft 适配层。先核对 cad-core、cad-contracts 和正式 UI 导出；按锁定 Registry 版本消费，候选与已发布包分别验证。不写个人 `file:` / `link:` 依赖，不改 node_modules 或公开包矩阵来绕过合同。

FreeCAD/Qt/进程副作用留在宿主适配，Vue UI 由 Desk Web 复用。确需独立 Python 小规则时标明原函数、来源与许可，做同语义对照，不冒称运行时调用了未接入的 TypeScript 包。

测试覆盖真实失败边界：事务回滚、观察器回调重名、来源变更、偏好恢复、晚到结果、重复请求、预算及取消。避免机械镜像实现的断言，不为纯样式或低影响改名堆测试；适用测试通过后不无理由反复扩大范围。mock 不替代原生 Qt/FreeCAD、几何或文件验收。

公开代码、文档、测试及发布包只保留可独立表述的通用接口、算法和能力；测试使用独立构造的中性 fixture。私有讨论、真实业务输入输出、使用经过及其摘要不得入库，去除姓名、路径或标识也不改变来源边界，不能把私有样本改名后作为公开fixture。原始本机验证材料留在仓库外受限目录，不提交或打包。

保护用户未保存文档、选择、视角和原偏好；不把生产模型、路径、令牌、PID/实例值或聊天 ID 写入仓库。实现、自动化、原生验收、归档与正式发布分别记录，历史证据不自动覆盖新版本。

版本按[VERSIONING](VERSIONING.md)维护：同一交付批次保留0.3.2候选号，不为每个修复或测试升号；旧内部0.4–0.10和实际运行版本是历史证据。归并前保留恢复备份，最终源码与实际包重新核对后再归档，发布另行记录。
